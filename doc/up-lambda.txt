AWSCLI:

1️⃣ Instalá AWS CLI:

brew install awscli

2️⃣ Verificá:

aws --version

PIPX:

1️⃣ Instalar pipx (con Homebrew):

brew install pipx
pipx ensurepath

2️⃣ Instalar awslocal:

pipx install awscli-local

3️⃣ Verificar:

awslocal --version
